| Feature           | **List**                  | **Tuple**            | **Set**               | **Dictionary**            |
| ----------------- | ------------------------- | -------------------- | --------------------- | ------------------------- |
| Syntax            | `[ ]`                     | `( )`                | `{ }`                 | `{key:value}`             |
| Type              | Sequence                  | Sequence             | Unordered Collection  | Mapping                   |
| Mutability        | **Mutable**               | **Immutable**        | **Mutable**           | **Mutable**               |
| Ordered           | **Yes**                   | **Yes**              | **No**                | **Yes** (3.7+)            |
| Indexed           | **Yes**                   | **Yes**              | **No**                | **By Key**                |
| Allows Duplicates | **Yes**                   | **Yes**              | **No**                | **Keys: No**, Values: Yes |
| Data Type Stored  | Values                    | Values               | Unique Values         | Key + Value               |
| Access Method     | Indexing                  | Indexing             | Membership Test       | Key Lookup                |
| Keys              | Not applicable            | Not applicable       | Not applicable        | **Unique & Immutable**    |
| Values            | Elements                  | Elements             | Elements              | Values mapped to keys     |
| Use Case          | Ordered & modifiable data | Fixed read-only data | Unique items, set ops | Structured data storage   |
| Performance       | Slower than tuple         | Fastest in lookup    | Fast membership tests | Fast key lookup           |
| Memory Usage      | Higher than tuple         | Lower than list      | Medium                | Higher                    |
| Methods Support   | Many                      | Few                  | Set ops               | Many (keys, values)       |
| Example           | `[10, 20, 30]`            | `(10, 20, 30)`       | `{10, 20, 30}`        | `{'a':10, 'b':20}`        |
